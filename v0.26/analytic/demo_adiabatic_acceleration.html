Adiabatic Acceleration ​

This example decomposes the energization of a guiding center (GC) into the three adiabatic acceleration channels:

  1. Betatron acceleration: conservation of while the particle sees change. It has a local part,  , and a convective part,   , which is the work done by the grad-B drift. The two are one mechanism, not two.

  2. Fermi acceleration: the curvature drift crossing the electric field,    .

  3. Parallel acceleration: direct work of the parallel electric field,   .

The fields are generated from a vector potential, so they satisfy    and     exactly, unlike a pair of independently prescribed and .

References:

  • Key Notes: Particle Acceleration

  • Northrop, T. G. (1963). The Adiabatic Motion of Charged Particles.

Physical Setup ​

Take an axisymmetric mirror described by the vector potential

which gives    and

The piece is the azimuthal field induced by the compression; adds a controllable without breaking Faraday's law, since the curl of a gradient vanishes.

julia
# --- Parameters (SI units) ---
const B₀₀ = 1.0e-3   # [T] field strength at the mirror midplane
const L = 30.0       # [m] mirror scale length
const α = 1 / L^2    # [m⁻²]
const β = 0.5        # [1/s] compression rate
const Epar0 = 5.0e-4 # [V/m] parallel electric field at the midplane
const L_E = 30.0     # [m] scale length of the parallel field
const v_mag = 5.0e4  # [m/s] initial speed
const pitch0 = 45.0  # [deg] initial pitch angle

const eV = TP.eV

g(z) = 1 + α * z^2
gp(z) = 2α * z

"""
    make_fields(βv)

The mirror field and its Faraday-consistent electric field for a compression rate
`βv`, using the module-level constants `B₀₀`, `α`, `Epar0` and `L_E`.
"""
function make_fields(βv)
    B(x, t = 0.0) = SA[
        -0.5 * B₀₀ * (1 + βv * t) * gp(x[3]) * x[1],
        -0.5 * B₀₀ * (1 + βv * t) * gp(x[3]) * x[2],
        B₀₀ * (1 + βv * t) * g(x[3]),
    ]
    E(x, t = 0.0) = SA[
        0.5 * B₀₀ * βv * g(x[3]) * x[2],
        -0.5 * B₀₀ * βv * g(x[3]) * x[1],
        Epar0 * (1 + x[3] / L_E),
    ]
    return B, E
end

const mirror_B, mirror_E = make_fields(β)

# --- Species and initial conditions ---
const species = Proton
const x0 = [2L, 0.0, 0.0]
const tspan = (0.0, 0.2)

"Initial full-orbit state with speed `v_mag` at pitch angle `pitch` [deg]."
function init_state(x0v, pitch, B)
    b̂ = normalize(B(x0v, 0.0))
    e1, _ = TP.get_perp_vector(b̂)
    θ = deg2rad(pitch)
    return [x0v..., (v_mag * (cos(θ) * b̂ + sin(θ) * e1))...]
end

# At the midplane the field is along +z, so the pitch angle maps directly onto v.
const stateinit = init_state(x0, pitch0, mirror_B)

Maxwell Check ​

Before tracing anything, verify that the pair really solves Maxwell's equations.

julia
let x = SA[60.0, 10.0, 15.0], t = 0.05
    Bf, Ef = TP.Field(mirror_B), TP.Field(mirror_E)
    JB = TP.jacobian(Bf, x, t)
    JE = TP.jacobian(Ef, x, t)
    curlE = SA[JE[3, 2] - JE[2, 3], JE[1, 3] - JE[3, 1], JE[2, 1] - JE[1, 2]]
    dBdt = TP.derivative_t(Bf, x, t)

    println("∇⋅B / ‖∇B‖          = ", round(abs(tr(JB)) / norm(JB), sigdigits = 2))
    println("‖∇×E + ∂B/∂t‖/‖∂B/∂t‖ = ", round(norm(curlE + dBdt) / norm(dBdt), sigdigits = 2))
end

GC Tracing ​

The guiding center is traced with a tight tolerance: the work-rate decomposition below is exact along the GC trajectory, so whatever mismatch is left comes from the time integration and must be resolved for the check to be meaningful.

julia
stateinit_gc, param_gc = prepare_gc(stateinit; E = mirror_E, B = mirror_B, species)
q, q2m, μ, Efunc, Bfunc = param_gc
m = q / q2m

sol_gc = solve(
    ODEProblem(trace_gc!, stateinit_gc, tspan, param_gc), Vern9();
    saveat = range(tspan..., length = 8001), reltol = 1.0e-12, abstol = 1.0e-10
)

vpar = [u[4] for u in sol_gc.u]
nbounce = count(i -> vpar[i] * vpar[i - 1] < 0, 2:length(vpar))
ε = [
    TP.adiabaticity_components(SA[u[1], u[2], u[3]], Bfunc, μ, t; species)
        for (u, t) in zip(sol_gc.u, sol_gc.t)
]
εmax = ntuple(i -> maximum(e[i] for e in ε), 3)

println("Magnetic moment μ = ", round(μ, sigdigits = 4), " J/T")
println("Bounces = ", nbounce)
println("Adiabaticity max over the orbit = ", round.(εmax, sigdigits = 2))

Energy Decomposition ​

get_work_rates returns the four leading-order terms . Since   ,

so the grad-B drift work is the convective part of the betatron channel rather than a fourth mechanism. get_work_channels performs that grouping and returns .

julia
"""
    accumulate_work(sol, p)

Instantaneous work rates, their trapezoidal time integrals, the GC kinetic energy
`K = ½ m v∥² + μ B`, and `|B|` along `sol`.
"""
function accumulate_work(sol, p)
    q, q2m, μ, _, Bf = p
    mass = q / q2m
    ts = sol.t
    n = length(ts)
    P = zeros(n, 4)
    K = zeros(n)
    Bmag = zeros(n)

    for (i, t) in enumerate(ts)
        u = sol.u[i]
        X = SA[u[1], u[2], u[3]]
        Bmag[i] = norm(Bf(X, t))
        K[i] = 0.5 * mass * u[4]^2 + μ * Bmag[i]
        P[i, :] .= TP.get_work_rates(u, p, t)
    end

    W = similar(P)
    W[1, :] .= 0
    for i in 2:n
        W[i, :] .= W[i - 1, :] .+ 0.5 .* (P[i, :] .+ P[i - 1, :]) .* (ts[i] - ts[i - 1])
    end

    return ts, P, W, K, Bmag
end

"""
    trace_case(x0v, pitch, tspan; βv = β, nout)

Trace a guiding center launched at `x0v` with pitch angle `pitch` [deg] in a mirror
compressed at rate `βv`, and return `(ts, W, ΔK)` in SI units.
"""
function trace_case(x0v, pitch, tspanv; βv = β, nout = 4001)
    B, E = make_fields(βv)
    sigc, p = prepare_gc(init_state(x0v, pitch, B); E, B, species)
    sol = solve(
        ODEProblem(trace_gc!, sigc, tspanv, p), Vern9();
        saveat = range(tspanv..., length = nout), reltol = 1.0e-12, abstol = 1.0e-10
    )
    ts, _, W, K, _ = accumulate_work(sol, p)

    return ts, W, K .- K[1]
end

ts, P, W, K, Bmag = accumulate_work(sol_gc, param_gc)

# Columns of P and W: 1 = parallel, 2 = Fermi, 3 = grad-B (convective part of
# betatron), 4 = ∂B/∂t (local part of betatron).
W_par = W[:, 1]
W_fermi = W[:, 2]
W_conv = W[:, 3]
W_loc = W[:, 4]
W_beta = W_conv .+ W_loc
W_total = W_par .+ W_fermi .+ W_beta
ΔK = K .- K[1]

Betatron and Fermi both grow secularly and end up within ~20 % of each other. The convective part of betatron is negative: the azimuthal induced field drives an inward   drift, and weakens toward the axis, so convection cools the perpendicular motion and cancels about half of the local   gain.

Why the parallel channel stays bounded ​

The purple curve oscillates and returns to zero instead of accumulating. Part of this is structural: the mirror is axisymmetric and is purely azimuthal, so the induced field is azimuthal as well and therefore perpendicular to the meridional . It carries no at all, and the whole parallel channel comes from . For the parameters used here the bounce motion together with the slow azimuthal drift keeps the guiding center close to where it started, so this conservative contribution is predominantly oscillatory: the energy taken from on the way up a bounce is handed back on the way down, and the net work stays near zero.

That is a statement about these parameters, not a theorem. The parallel channel integrates    along the path the guiding center actually samples, and the azimuthal   drift does move the particle across equipotential surfaces of . A steeper or less symmetric potential, or a drift that moves systematically in one direction, does let a trapped particle gain energy from .

Net parallel acceleration is easiest to see on an orbit that does not return. Launching the same particle at the throat with a small pitch angle makes it stream through the mirror instead of bouncing, and the channel switches on:

Over a single transit the compression has barely acted ( ), so betatron is negligible and the parallel channel dominates: the particle slides monotonically down and converts   into kinetic energy once. Reversing the motion would hand that energy back, which is approximately what the trapped orbit does over each of its bounces.

Parameter Study ​

Raising the compression rate strengthens the induced electric field and the field growth together, so betatron and Fermi scale linearly, while the parallel channel, being bounded, does not.

julia
β_cases = [0.0, 0.25, 0.5, 0.75, 1.0]
channels = zeros(length(β_cases), 3)

for (k, βv) in enumerate(β_cases)
    _, Wv, _ = trace_case(x0, pitch0, tspan; βv, nout = 4001)
    channels[k, 1] = Wv[end, 1]                  # parallel
    channels[k, 2] = Wv[end, 2]                  # Fermi
    channels[k, 3] = Wv[end, 3] + Wv[end, 4]     # betatron
end

f4 = Figure(size = (850, 500), fontsize = 14)
ax_scan = Axis(
    f4[1, 1], title = "Channel contributions vs. compression rate",
    xlabel = "β [1/s]", ylabel = "Energy gain [eV]",
)
scatterlines!(
    ax_scan, β_cases, channels[:, 1] ./ eV, color = :purple, linewidth = 2,
    markersize = 12, label = L"E_\parallel"
)
scatterlines!(
    ax_scan, β_cases, channels[:, 2] ./ eV, color = :teal, linewidth = 2,
    markersize = 12, label = L"\mathrm{Fermi}"
)
scatterlines!(
    ax_scan, β_cases, channels[:, 3] ./ eV, color = :coral, linewidth = 2,
    markersize = 12, label = L"\mathrm{Betatron}"

axislegend(ax_scan; position = :lt)

At   the field is static, no electric field is induced, and both betatron and Fermi vanish identically: all that remains is the bounded parallel channel. Switching the compression on adds the two channels that can actually energize a trapped particle.
