Hybrid GC-FO Solver ​

This example demonstrates AdaptiveHybrid, which dynamically switches between full-orbit (FO) and guiding-center (GC) tracing based on a local adiabaticity parameter such as ε = ρ_L / R_c.

We use a divergence-free curved magnetic loop where the field strength varies by nearly two orders of magnitude along circular field lines: in the strong-field mirror legs ε is small (adiabatic → GC), whereas near the weak-field loop apex ε exceeds the switching threshold (non-adiabatic → FO).

julia
using TestParticle, OrdinaryDiffEqVerner, StaticArrays
using BorisPushers
using TestParticle: get_adiabaticity
import TestParticle as TP
using LinearAlgebra, Printf, Markdown
using Chairmarks, Statistics
using CairoMakie

Curved Magnetic Loop Configuration ​

Derived from the 2-D line-dipole flux function

the magnetic field    satisfies    identically:

Every field line    is a circle of constant curvature radius   whose field magnitude   grows strongly toward the footpoints near   and weakens at the apex  .

julia
const M_LOOP = 1.6e-5   # [T m²]; gives |B| = 1 μT at the D = 4 m apex
const X_OFFSET = 3.0    # [m]; line-dipole origin at (x = -3 m, z = 0)
const D_LINE = 4.0      # [m]; field-line circle diameter

function curved_B(x, t = 0.0)
    X = x[1] + X_OFFSET
    z = x[3]
    r2 = X * X + z * z
    r4 = r2 * r2
    return SA[
        -2 * M_LOOP * X * z / r4,
        0.0,
        M_LOOP * (X * X - z * z) / r4,
    ]
end

m = Proton.m
q = Proton.q
q2m = q / m;

Step 1: Full-Orbit Reference Trace ​

We launch a proton in the southern strong-field leg (r_start = 0.75 m on the D = 4 m field line, where |B| is 28× stronger than at the apex) with speed 42 m/s and pitch angle 65°. The proton bounces between conjugate mirror points while curvature and ∇B drifts carry it along -y.

julia
r_start = 0.75
v_tot = 42.0
pitch_deg = 65.0

X0 = r_start^2 / D_LINE
z0 = -sqrt(r_start^2 - X0^2)
x0 = SA[X0 - X_OFFSET, 0.0, z0]
B0_vec = curved_B(x0)
B0_mag = norm(B0_vec)
b0 = B0_vec / B0_mag
α0 = deg2rad(pitch_deg)
v0 = v_tot * (cos(α0) * b0 + sin(α0) * SA[0.0, 1.0, 0.0])
u0 = vcat(x0, v0)

B_apex = M_LOOP / D_LINE^2
T_gyro_0 = 2π / (abs(q2m) * B0_mag)
T_gyro_apex = 2π / (abs(q2m) * B_apex)
tspan = (0.0, 1.2)

param_fo = prepare(; B = curved_B, species = Proton)
prob_fo = TraceProblem(u0, tspan, param_fo)
sol_fo = solve(prob_fo, Vern7(); abstol = 1.0e-7, reltol = 1.0e-7, dense = true)

alg_boris = AdaptiveBoris(; safety = 0.04)
sol_boris = solve(
    prob_fo, alg_boris; dtmax = T_gyro_apex, dtmin = 1.0e-3 * T_gyro_0
);

Step 2: Guiding-Center Reference Trace ​

Standalone guiding-center integration evolves assuming the first adiabatic invariant remains strictly constant across the weak-field apex.

julia
u0_gc, param_gc = prepare_gc(u0; B = (x) -> curved_B(x), species = Proton)
prob_gc = TraceGCProblem(SVector{4}(u0_gc), tspan, param_gc)
sol_gc = solve(prob_gc, Vern7(); abstol = 1.0e-7, reltol = 1.0e-7, dense = true);

Step 3: Adaptive Hybrid Solver ​

AdaptiveHybrid uses hysteresis thresholds (threshold_gc_to_fo ≥ threshold_fo_to_gc) to switch cleanly from GC to FO entering the curved weak-field apex and back to GC in the strong-field mirror legs without chattering.

julia
thr_gc_to_fo = 0.1
thr_fo_to_gc = 0.08

alg = AdaptiveHybrid(;
    threshold_gc_to_fo = thr_gc_to_fo,
    threshold_fo_to_gc = thr_fo_to_gc,
    dtmax = T_gyro_apex,
    dtmin = 1.0e-2 * T_gyro_0,
    safety_fo = 0.04,
    check_dt = 0.25 * T_gyro_apex,
    check_interval = 4,
    abstol = 1.0e-7,
    reltol = 1.0e-7,
    maxiters = 500_000,
)

sol = solve(prob_fo, alg; verbose = false, seed = 42).u[1];

Step 4: Visualization ​

Comparing the 3-D trajectories alongside the poloidal (x–z) projection and the recorded mode timeline shows that pure GC misses the non-adiabatic mirror shift across the apex, whereas AdaptiveHybrid tracks the full-orbit trajectory while stepping rapidly through the strong-field mirror bounces.

function cubic_eval(t::AbstractVector{Float64}, y::AbstractVector{Float64}, ts)
    n = length(t)
    h = diff(t)
    dl = h[1:(n - 2)]
    du = h[2:(n - 1)]
    d = 2.0 .* (dl .+ du)
    rhs = 6.0 .* ((y[3:n] .- y[2:(n - 1)]) ./ du .- (y[2:(n - 1)] .- y[1:(n - 2)]) ./ dl)
    m_c = vcat(0.0, SymTridiagonal(d, h[2:(n - 2)]) \ rhs, 0.0)
    out = Vector{Float64}(undef, length(ts))
    for (k, tq) in enumerate(ts)
        i = clamp(searchsortedlast(t, tq), 1, n - 1)
        hi = h[i]
        a = (t[i + 1] - tq) / hi
        b = (tq - t[i]) / hi
        out[k] = a * y[i] + b * y[i + 1] +
            ((a^3 - a) * m_c[i] + (b^3 - b) * m_c[i + 1]) * (hi^2 / 6.0)
    end
    return out
end

function sample_dense(s, eps_vals, npts)
    ts = range(s.t[1], s.t[end]; length = npts)
    es = cubic_eval(s.t, eps_vals, ts)
    xs = Vector{Float64}(undef, npts)
    ys = Vector{Float64}(undef, npts)
    zs = Vector{Float64}(undef, npts)
    for (i, t) in enumerate(ts)
        u = s(t)
        xs[i], ys[i], zs[i] = u[1], u[2], u[3]
    end
    return xs, ys, zs, es
end

function sample_spline(s, eps_vals, npts)
    keep = [i == 1 || s.t[i] > s.t[i - 1] for i in eachindex(s.t)]
    t_u = s.t[keep]
    u_u = s.u[keep]
    e_u = eps_vals[keep]
    ts = range(t_u[1], t_u[end]; length = npts)
    return (
        cubic_eval(t_u, [u[1] for u in u_u], ts),
        cubic_eval(t_u, [u[2] for u in u_u], ts),
        cubic_eval(t_u, [u[3] for u in u_u], ts),
        cubic_eval(t_u, e_u, ts),
    )
end

function shade_modes!(ax, t, mode; alpha = 0.18)
    for i in 1:(length(t) - 1)
        t[i + 1] > t[i] || continue
        c = mode[i] === :FO ? (:red, alpha) : (:blue, alpha)
        vspan!(ax, t[i], t[i + 1]; color = c)
    end
    return nothing
end

Accuracy and Performance Comparison ​

Because full-orbit integrators must resolve hundreds of short gyroperiods inside the strong-field mirror legs where the motion is deeply adiabatic, AdaptiveHybrid achieves near-GC execution speed while preserving full-orbit accuracy across the curved apex:

julia
function energy_drift(s)
    e = map(s.u) do u
        length(u) == 6 && return 0.5 * m * sum(abs2, u[SA[4, 5, 6]])
        x = SA[u[1], u[2], u[3]]
        return 0.5 * m * u[4]^2 + param_gc.μ * norm(curved_B(x))
    end
    return (maximum(e) - minimum(e)) / e[1]
end

end_pos_err(s) = norm(s.u[end][1:3] - sol_fo.u[end][1:3])

Adiabaticity Check Modes ​

AdaptiveHybrid lets the user select which local criterion drives the GC ↔ FO decision via the adiabaticity keyword:

  • :curvature (default): ε_curv = ρ_L / R_c, scaling as (r / D)² along a circular loop of radius D / 2;

  • :gradB: ε_gradB = ρ_L / L_B with L_B = |B| / |∇B| = r / 2, scaling linearly as r / D and therefore switching earlier in the converging legs;

  • :both: max(ε_curv, ε_gradB);

  • :jacobian: ε_jac = ρ_L · ‖∇B‖_F / |B|, capturing curvature, gradient, torsion, and shear simultaneously.

julia
mode_kw = (;
    threshold_gc_to_fo = thr_gc_to_fo,
    threshold_fo_to_gc = thr_fo_to_gc,
    dtmax = T_gyro_apex,
    dtmin = 1.0e-2 * T_gyro_0,
    safety_fo = 0.04,
    check_dt = 0.25 * T_gyro_apex,
    check_interval = 4,
    abstol = 1.0e-7,
    reltol = 1.0e-7,
    maxiters = 500_000,
)

alg_curv = AdaptiveHybrid(; mode_kw..., adiabaticity = :curvature)
alg_gradB = AdaptiveHybrid(; mode_kw..., adiabaticity = :gradB)
alg_both = AdaptiveHybrid(; mode_kw..., adiabaticity = :both)
alg_jac = AdaptiveHybrid(; mode_kw..., adiabaticity = :jacobian)

sol_both = solve(prob_fo, alg_both; verbose = false, seed = 42).u[1]
sol_jac = solve(prob_fo, alg_jac; verbose = false, seed = 42).u[1];

function fo_time_frac(s)
    ad = s.stats.adiabaticity
    isempty(ad.t) && return 0.0
    t_end = s.t[end]
    t_fo = 0.0
    for i in eachindex(ad.t)
        t_hi = i < length(ad.t) ? ad.t[i + 1] : t_end
        ad.mode[i] === :FO && (t_fo += t_hi - ad.t[i])
    end
    return t_fo / (t_end - ad.t[1])
end

function rms_diff(s)
    errs = [norm(u[1:3] - sol_fo(t)[1:3]) for (t, u) in zip(s.t, s.u)]
    return sqrt(mean(errs .^ 2))
end
